# La Marmite d'Afrique 🍲🌍

Bienvenue dans le projet **La Marmite d'Afrique**, un site web dynamique pour un restaurant. Ce projet utilise **React**, **Tailwind CSS** et **Framer Motion** pour offrir une expérience fluide et interactive aux utilisateurs.

## 📋 Description

Le site permet aux utilisateurs de découvrir un menu interactif et personnalisé. Il inclut des animations et des transitions pour améliorer l'expérience utilisateur. Le projet met en avant les différentes spécialités du restaurant et permet de naviguer facilement entre les différentes sections du site.

## ⚡ Fonctionnalités

- Affichage du menu du restaurant 🍽️
- Animations de transition fluides avec **Framer Motion** 🎬
- Mise en page responsive grâce à **Tailwind CSS** 📱
- Design moderne et épuré 🎨

## 🛠️ Prérequis

Avant de commencer, assurez-vous que vous avez installé les éléments suivants :

- **Node.js** et **npm** (ou **yarn**) 🧰
- **VS Code** (ou un autre éditeur de code) 💻
